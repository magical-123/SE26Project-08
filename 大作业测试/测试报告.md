# InfoDigest JUnit/Mockito 测试报告

## 1. 测试目标

验证认证、安全、数据清洗、观看时长和营养报告核心逻辑，重点检查异常输入和越权访问。

## 2. 执行命令

```powershell
cd backend
mvn test '-Dmaven.compiler.useIncrementalCompilation=false'
```

## 4. 测试结论

核心单元测试全部通过。测试使用 Mockito 隔离 UserRepository、FriendshipRepository、InformationItemRepository、JWT 和调度器等外部依赖，不连接生产数据库或真实 AI 服务。

## 5. 局限性

本报告不等同于系统级验收报告。Repository、MySQL、Redis、AI API、前端页面和浏览器扩展仍需集成测试与端到端测试。
