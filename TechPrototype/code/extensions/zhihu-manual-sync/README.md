# InfoDigest 知乎手动同步扩展（PoC）

此扩展只在用户点击“同步当前知乎页面”时读取当前标签页已渲染的知乎内容卡片，并写入本地运行的 InfoDigest Inbox。它不会读取或上传知乎 Cookie，也不会自动滚动、模拟点赞/收藏或后台抓取。

## 安装和测试

1. 确保 InfoDigest 后端已运行在 `http://127.0.0.1:8080`。
2. Chrome/Edge 打开扩展管理页，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，目录选本文件夹。
4. 在真实浏览器中登录知乎，打开首页、发现页或“最近浏览”页面；如同步信息流，请先向下滚动加载几条内容。
5. 点击扩展图标，用 InfoDigest 账号登录，然后点击“同步当前知乎页面”。
6. 打开 InfoDigest Inbox，确认新增的 `ZHIHU` 卡片。

## 限制

- 只能同步当前页面已经显示的内容。因此打开“最近浏览”后可以同步该页面已加载的记录，但不能绕过平台分页去读取未显示的历史、点赞或收藏。
- 后端按“标题 + 平台”去重，重复同步会被跳过。
- JWT 仅保存在浏览器扩展的本地存储中；退出或失效后重新登录即可。
