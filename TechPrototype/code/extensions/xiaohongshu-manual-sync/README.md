# InfoDigest 小红书手动同步扩展（PoC）

在真实 Chrome/Edge 中正常登录小红书并打开发现页或搜索结果页后，点击扩展即可把当前已经加载的笔记同步到 InfoDigest Inbox。

## 安装

1. 保持 InfoDigest 后端运行在 `http://127.0.0.1:8080`。
2. 打开浏览器扩展管理页，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开小红书页面，等待或滚动加载笔记。
5. 点击扩展图标，登录 InfoDigest 后点击“同步当前小红书页面”。

## 边界

- 只读取当前页面已显示的笔记，不读取或上传小红书 Cookie。
- 不自动滚动、点赞、收藏或后台采集。
- 不能同步小红书未向 Web 页面开放的个人浏览历史、点赞和收藏。
