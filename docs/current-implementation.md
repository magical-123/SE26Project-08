# 当前实现与文档口径（2026-07）

## 平台采集

- Bilibili、GitHub：后端授权抓取，调度器每小时运行。
- 知乎、小红书：浏览器扩展捕获详情页，前台心跳间隔 5 秒。
- 知乎和小红书不自动抓取推荐流，不回补历史浏览、点赞或收藏记录。

## 数据与报告

- Inbox 接口最多返回最近 1000 条内容。
- 真实浏览时长统一使用 `watchDurationSeconds`。
- `durationMinutes` 表示内容原始/估算时长，不作为真实观看时长统计。
- 元数据标题（如“发布于……”）由服务端统一拒绝。

## 架构

- 数据库：MySQL。
- 缓存与队列：Redis/Redisson。
- 知识图谱：MySQL 存储，前端 AntV G6 渲染。
- 不采用 Neo4j。

## 测试状态

当前后端核心 JUnit 测试共 15 个，已覆盖认证、JWT、加密、Inbox 标题规则、时长统计、报告营养计算和关键权限场景。Repository、Redis、AI 服务、前端和浏览器插件的集成测试仍需单独建设。
