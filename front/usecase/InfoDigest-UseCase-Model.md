# InfoDigest（知食）— Use-Case 模型

> **项目名称**：InfoDigest（知食）— 全域碎片化信息捕获与数字饮食管理平台  
> **文档类型**：需求分析 · Use-Case 模型  
> **版本**：v1.0

---

## 1. 参与者（Actors）

| 参与者 | 标识 | 描述 |
|--------|------|------|
| 👤 **用户** | `User` | 平台直接使用者，管理信息源、做笔记、查看报告与图谱、社交互动 |
| 👥 **好友** | `Friend` | 社交场景中对应用户，建立好友后可互相查看公开内容 |
| 🤖 **系统** | `System` | 后台自动执行定时抓取、AI 分析、报告生成、智能推送 |

---

## 2. 用例总览

共 **18 个用例**，按 6 个功能模块组织：

### 2.1 信息源管理

| ID | 用例名 | 参与者 | 简要描述 |
|----|--------|--------|----------|
| UC-01 | **授权信息源接入** | 用户 | 通过 Cookie 授权或 MCP 技术绑定第三方平台（B站、知乎、播客等） |
| UC-02 | **自动捕获浏览记录** | 系统 | 隐式获取用户在授权平台上的浏览记录与交互行为 |
| UC-03 | **查看信息源元数据** | 用户 | 浏览结构化展示的信息源标题、来源平台、作者、浏览时长等 |
| UC-05 | **接收智能引导提示** | 用户 | 系统检测到高意向行为（点赞/收藏/长时停留）时主动推送轻量提示 |

```
用户 ─── UC-01 授权信息源接入
用户 ─── UC-03 查看信息源元数据
用户 ─── UC-05 接收智能引导提示
系统 ─── UC-02 自动捕获浏览记录 ──<<extend>>──→ UC-01
                                            (授权后触发)
```

## 6. Use-Case 详细说明

### UC-01：授权信息源接入

| 项目 | 内容 |
|------|------|
| **描述** | 用户通过 Cookie 授权或 MCP 技术绑定第三方平台信息源 |
| **参与者** | 用户 |
| **前置条件** | 用户已注册并登录 InfoDigest |
| **后置条件** | 系统获得授权，开始自动捕获该平台浏览记录 |
| **基本流程** | ① 用户选择目标平台 → ② 选择授权方式（Cookie/MCP）→ ③ 完成授权流程 → ④ 系统验证授权有效性 → ⑤ 绑定成功 |
| **扩展点** | UC-02 扩展 UC-01：授权成功后触发自动捕获 |

### UC-04：记录笔记并标注优质源

| 项目 | 内容 |
|------|------|
| **描述** | 用户对某个信息源撰写笔记，阐述喜欢的原因或触动点，标注为"优质信息源" |
| **参与者** | 用户 |
| **前置条件** | 用户已浏览信息源列表 |
| **后置条件** | 该信息源被标记为优质，触发 UC-10 构建知识图谱 |
| **基本流程** | ① 用户选择信息源 → ② 撰写笔记 → ③ 提交 → ④ 系统将该信息源升级为"优质信息源" |
| **扩展点** | 标注后触发 UC-10 AI 构建知识图谱 |

### UC-06：查看每日/周知识总结报告

| 项目 | 内容 |
|------|------|
| **描述** | 自动生成每日或每周的知识摄入总结报告推送给用户 |
| **参与者** | 用户、系统 |
| **前置条件** | 用户已有至少一个已授权的信息源且有浏览记录 |
| **后置条件** | 无 |
| **包含** | UC-07（信息营养成分表）、UC-08（关注点流变分析） |

### UC-14：管理隐私设置

| 项目 | 内容 |
|------|------|
| **描述** | 用户按平台、话题标签或单个图谱节点设置对好友的可见性 |
| **参与者** | 用户 |
| **前置条件** | 用户已登录 |
| **后置条件** | 好友查看用户信息时受隐私设置约束 |
| **约束对象** | UC-12（查看好友浏览趋势）、UC-13（查看好友知识图谱） |

## 7. 非功能性需求映射

| 非功能性需求 | 关联用例 |
|-------------|---------|
| Web 端响应式设计（PC + 移动端） | UC-03, UC-06, UC-07, UC-08, UC-09 |
| Cookie 加密脱敏存储与过期机制 | UC-01 |
| 抓取频次控制以防触发风控 | UC-02 |
| AI 营养分类准确率 > 85% | UC-07, UC-10 |
| WebGL 流畅渲染 ≥ 1000 个图谱节点 | UC-09 |
| 异步批量拉取不阻塞正常响应 | UC-02, UC-10 |
| 多模态大模型音视频理解 | UC-16 |
